# Woven Software

Woven Software, Inc. (Woven, woven.com) was a Mountain View, California startup that built an AI-powered calendar and scheduling application. It raised roughly $4.8M from investors including Battery Ventures, Felicis, Amplify Partners, Salesforce Ventures, and the Slack Fund. Slack acquired the Woven team in an acqui-hire announced in April 2021 and the Woven calendar product was shut down.

**Status: defunct (acquired by Slack, 2021).** The company no longer operates and publishes no APIs, developer portal, or other public API artifacts, so this profile carries no API surface. It is retained in the network as an exited Battery Ventures portfolio investment.
